# 쿠팡 상품등록 어시스턴트

도매 상품 정보를 넣으면 쿠팡 WING 상품등록 폼의 14개 섹션 입력값을 만들어 주는 웹앱.
`cupang_PRD.md`의 Phase 1(코어) 범위를 구현한 버전이다.

## 실행

```bash
npm install
```

프로젝트 루트에 `.env.local` 파일을 만들고 Gemini API 키를 넣는다.

```
GEMINI_API_KEY=발급받은_키
```

키는 [Google AI Studio](https://aistudio.google.com/apikey)에서 발급받는다.
키는 서버에서만 사용되며 브라우저로 나가지 않는다.

```bash
npm run dev
```

http://localhost:3000 접속.

## 화면

| 경로 | 내용 |
|---|---|
| `/` | 상품 정보·크기·원가 수기 입력 + 실시간 마진 계산기 |
| `/result` | WING 폼 순서 그대로 14개 섹션 + 정책 검사 결과 + 남은 작업 |

## 구조

생성은 **규칙 엔진 + Gemini 하이브리드**다. 판단이 규칙화되는 항목은 순수 함수로 처리해
결과를 결정적으로 만들고, 언어적 창의성이 필요한 항목만 Gemini가 만든다.

| 처리 | 대상 |
|---|---|
| 규칙 엔진 (`src/lib/rules.ts`) | ①카탈로그매칭 ②판매방식 ⑥⑦이미지규격 ⑧주요정보 ⑩검색필터 ⑪고시정보 ⑫구비서류 ⑬물류입고 ⑭검수체크리스트 |
| Gemini (`src/lib/gemini.ts`) | ③노출상품명 3안 ④카테고리 선택 ⑤사이즈 라벨 ⑨검색어 20개 |
| 마진 계산 (`src/lib/margin.ts`) | 부가세·수수료·입고배송비·물류비 반영, 마진율 구간별 경고 |
| 정책 검사 (`src/lib/policyCheck.ts`) | 금지어·소재 연동 차단·A/S 번호 검사 |

### 데이터 파일 (`src/data/`)

쿠팡 정책이 바뀌면 코드가 아니라 이 JSON들을 고친다.

| 파일 | 내용 |
|---|---|
| `policyWords.json` | 금지어·위험 표현. 등급(block/warn), 사유, 대안, 소재 조건부 규칙 |
| `categories.json` | 카테고리 경로 + 판매수수료율. 수수료율은 마진 계산에 직결된다 |
| `filterTemplates.json` | 카테고리별 검색필터 항목과 선택지 |
| `noticeTemplates.json` | 상품정보제공고시 카테고리별 항목 세트 |

### 내장된 안전장치

- 소재가 PET·PVC·PP·아크릴이면 식기세척기·열탕·내열 표현을 전부 차단하고, 검색필터의
  `세척 용이성`도 `손세척`으로 강제한다.
- 옵션 사이즈에 `소형`·`미니`·`Free`가 나오면 경고하고 구조·수치 라벨 대안을 제시한다.
- A/S 연락처에 일반 유선/휴대폰 번호가 들어오면 차단하고 안심번호(050·0507)를 안내한다.
- 로켓그로스 물류비를 비우면 마진을 추정하지 않고 `확정 불가`로 표시한다.
- 구성품 체크리스트는 "구성품 확인"이 아니라 "기둥 3개 확인"처럼 개수까지 표시한다.
