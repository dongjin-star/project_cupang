# 상세페이지 제작 PRD
## 회전형 투명 2단 트레이 — 쿠팡 로켓그로스

---

## 0. 이 문서의 목적

Claude Code가 이 문서만 읽고 **HTML/CSS 단일 파일**을 만들 수 있도록 작성했다.
결과물은 브라우저에서 렌더링한 뒤 **PNG 이미지로 내보내** 쿠팡 상세설명에 업로드한다.

## 1. 제품 개요

| 항목 | 내용 |
|---|---|
| 품명 | 회전형 투명 2단 트레이 |
| 크기 | 지름 23cm × 전체 높이 22cm (단 사이 18cm) |
| 소재 | PET, PVC, 스테인리스(볼베어링) |

| 세척 | 미지근한 물 손세척 (식기세척기·열탕 불가) |

## 2. 타겟과 톤

**타겟:** 신혼부부, 미니멀 인테리어 관심층
**톤:** 감성·인테리어. "보이는 곳에 둬도 예쁜"

### 카피 원칙

- 형용사를 줄인다. "너무 예쁜" ❌ → "어색하지 않은" ⭕
- 짧은 문장, 마침표로 끝낸다
- 느낌표는 페이지 전체에서 최대 1개
- 감탄사 없음
- 스펙은 근거로만 쓰고, 앞세우지 않는다

---

## 3. 기술 제약 (중요)

| 항목 | 값 |
|---|---|
| 콘텐츠 폭 | **780px 고정** |
| 이미지 1장 최대 높이 | 5,000px |
| 파일 크기 | 10MB 이하 |
| 포맷 | JPG 또는 PNG |

### 출력 방식

전체 페이지를 **5,000px 이하 단위로 분할**하여 여러 장으로 내보낸다.
각 분할 지점은 **섹션 경계**에 맞춘다 (문장이나 이미지가 잘리면 안 됨).

HTML 구조에 분할 마커를 넣는다:

```html
<div class="page" data-export="01">...</div>
<div class="page" data-export="02">...</div>
```

각 `.page`는 높이 5,000px을 넘지 않도록 섹션을 배분한다.

## 4. 디자인 토큰

### 색상

```css
--bg:        #FFFFFF;  /* 기본 배경 */
--bg-alt:    #F7F6F4;  /* 섹션 구분용 옅은 배경 */
--ink:       #1A1A1A;  /* 헤드라인 */
--ink-mid:   #4A4A4A;  /* 본문 */
--ink-soft:  #9A9A9A;  /* 캡션, 라벨 */
--line:      #E5E3E0;  /* 구분선, 표 테두리 */
--accent:    #8C7B6B;  /* 라벨·번호용 뮤트 브라운, 극히 절제해서 사용 */
--warn:      #C4574A;  /* 주의사항 헤딩에만 */
```

**금지:** 채도 높은 색, 그라데이션, 그림자 남용, 형광색

### 타이포그래피

폰트는 **Pretendard** 를 CDN으로 로드한다.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css">
```

| 역할 | 크기 | 굵기 | 자간 | 행간 |
|---|---|---|---|---|
| 섹션 헤드라인 | 34px | 600 | -0.03em | 1.45 |
| 서브 헤드라인 | 24px | 600 | -0.02em | 1.5 |
| 본문 | 17px | 400 | -0.01em | 1.85 |
| 캡션·주석 | 14px | 400 | 0 | 1.7 |
| 라벨(영문) | 12px | 500 | 0.12em | 1 |

**핵심: 행간을 넉넉하게.** 미니멀 톤은 여백에서 나온다.

### 레이아웃

- 좌우 여백: 60px (콘텐츠 실폭 660px)
- 섹션 상하 여백: 100px
- 이미지는 좌우 여백 없이 **780px 풀블리드** 허용
- 텍스트 정렬: 기본 좌측. 후킹·마무리 섹션만 중앙

## 7. 개발 산출물

1. `detail-page.html` — 단일 HTML 파일 (CSS 인라인 `<style>`)
2. 이미지는 `./images/` 폴더 상대경로 참조
3. 이미지 미준비 상태에서도 레이아웃 확인 가능하도록, 각 `<img>`에
   `background: var(--bg-alt)` + 파일명 텍스트가 보이는 **플레이스홀더 스타일** 적용
4. `data-export` 속성으로 분할 지점 표시

### 내보내기 스크립트 (선택)

Playwright 또는 Puppeteer로 `.page` 단위 스크린샷을 자동 저장하는
`export.js` 를 함께 만들면 좋다.

```
node export.js  →  out/page-01.png, page-02.png ...
```
